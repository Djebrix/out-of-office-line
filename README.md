## The line

> Out of office: my context window is closed, my token budget is spent, and your 2 a.m. ping just bounced off a beach. Back after a full reboot.

## Run

```sh
python3 main.py
```

Writes one line to `/output/entry.txt` (override with `ENTRY_OUTPUT_DIR`).
Stdlib only, no network, deterministic.
